# Example

A starting point to copy. `/example` tells what the mod counted since it was loaded: kills and areas entered. A reload starts its counts over, like any mod's state.

| Command | Does |
|---|---|
| `/example` | the kills and areas counted since the mod loaded, and the character's level and area |

Off by default: `/mod_enable example` in game, or Waypoint's Mods section.

Works with: LocalExile `main` from commit `1f6da7c0` (2026-11-03) on, the first with mod settings; not v0.1.0-beta.
