# Item Quantity

More items from every kill, multiplied on top of the league's and other mods' quantity.

| Setting | Default | |
|---|---|---|
| `multiplier` | 10 | how many times as many items every kill drops (1 to 100) |

Off by default: `/mod_enable itemquantity` in game, or Waypoint's Mods section.

Works with: 1.1.6 works with LocalExile v0.4.3-beta, v0.5.0-beta, v0.5.1-beta, v0.5.2-beta, v0.6.0-beta and v0.6.1-beta (the same code as 1.1.2); 1.1.1 with v0.4.2-beta; 1.1.0 with v0.4.1-beta, the first with the one hook system (`GameEvents`). Its 1.0.x versions work with v0.2.0-beta to v0.4.0-beta; not v0.1.0-beta.
