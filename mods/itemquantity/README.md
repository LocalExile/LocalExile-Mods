# Item Quantity

More items from every kill, multiplied on top of the league's and other mods' quantity.

| Setting | Default | |
|---|---|---|
| `multiplier` | 10 | how many times as many items every kill drops (1 to 100) |

Off by default: `/mod_enable itemquantity` in game, or Waypoint's Mods section.

Works with: LocalExile v0.2.0-beta, v0.2.1-beta, v0.2.2-beta and v0.3.0-beta, and `main` from commit `1f6da7c0` (2026-11-03) on, the first with mod settings; not v0.1.0-beta.
