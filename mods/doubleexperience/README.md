# Double Experience

More experience from kills, after the level penalty.

| Setting | Default | |
|---|---|---|
| `multiplier` | 2 | how many times the experience every kill gives (1 to 100) |

Off by default: `/mod_enable doubleexperience` in game, or Waypoint's Mods section.

Works with: LocalExile `main` from commit `1f6da7c0` (2026-11-03) on, the first with mod settings; not v0.1.0-beta.
