# Boss Loot

An extra item from every monster of the chosen rarities: by default an Exalted Orb from every unique monster.

| Setting | Default | |
|---|---|---|
| `item` | Exalted Orb | the extra item, any of the game's items |
| `rarities` | unique | the monster rarities that drop it: normal, magic, rare, unique |

Off by default: `/mod_enable bossloot` in game, or Waypoint's Mods section.

Works with: LocalExile `main` from commit `1f6da7c0` (2026-11-03) on, the first with mod settings; not v0.1.0-beta.
